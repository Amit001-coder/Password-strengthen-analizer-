# 🔐 Password Strength Analyzer & Generator

A simple Python cybersecurity project that checks password strength and generates secure random passwords.

Built as part of my **Cybersecurity Internship at THIRANEX**.

## ✨ Features

- Checks password length
- Detects uppercase and lowercase letters
- Detects numbers and special characters
- Detects common passwords
- Detects some predictable patterns
- Gives a Weak / Medium / Strong rating
- Provides suggestions to improve weak passwords
- Generates random passwords using Python's `secrets` module
- Hides password input using `getpass`

## 🛠️ Technologies

- Python 3
- Git & GitHub
- Python Standard Library
